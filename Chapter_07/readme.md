# Chapter 7: Traversal Algorithms

This chapter focuses on tree and graph traversal algorithms, specifically applying them to file system traversal. 

It demonstrates how both **Breadth-First Search (BFS)** and **Depth-First Search (DFS)** can be utilized to traverse and list the contents of directories on an operating system.

## 📂 Contents

- `ls_by_BFS.py`: Directory listing implementation using Breadth-First Search.
- `ls_by_DFS.py`: Directory listing implementation using Depth-First Search.

## 🚀 How to Run

```bash
python3 ls_by_BFS.py
python3 ls_by_DFS.py
```
