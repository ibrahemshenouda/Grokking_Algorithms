# Chapter 10: Greedy Algorithms

This chapter covers **Greedy Algorithms**. A greedy algorithm makes the locally optimal choice at each stage with the hope of finding a global optimum. They are often used for optimization problems where finding the absolute perfect solution is too slow (NP-complete problems), so a "good enough" approximation is required.

## 📂 Contents

- `greedy.py`: A Python implementation demonstrating a greedy algorithm approach (e.g., the set-covering problem).

## 🚀 How to Run

```bash
python3 greedy.py
```
