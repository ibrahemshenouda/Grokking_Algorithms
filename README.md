# Grokking Algorithms Implementations

Welcome to the **Grokking Algorithms** repository! This project contains code implementations and practical exercises based on the concepts taught in the book *"Grokking Algorithms"*. 

The repository includes implementations primarily in **Python**, with some examples in **C++**. It serves as a hands-on reference for essential algorithms and data structures.

## 🗂️ Repository Structure

The code is logically organized by chapters, corresponding to the progression of algorithms covered:

| Chapter | Topic / Algorithm | Implementations |
|---|---|---|
| **[Chapter 01](./Chapter_01)** | Introduction to Algorithms | Binary Search (`.py`, `.cpp`) |
| **[Chapter 02](./Chapter_02)** | Selection Sort | Selection Sort (`.py`) |
| **[Chapter 03](./Chapter_03)** | Recursion | Factorial, Countdown (`.py`) |
| **[Chapter 04](./Chapter_04)** | Quicksort | Divide and Conquer, Quicksort |
| **[Chapter 05](./Chapter_05)** | Hash Tables | Hash Table (`.py`) |
| **[Chapter 06](./Chapter_06)** | Breadth-First Search (BFS) | Graph representation and BFS (`.py`) |
| **[Chapter 07](./Chapter_07)** | Traversal Algorithms | Directory listing via BFS and DFS (`.py`) |
| **[Chapter 09](./Chapter_09)** | Dynamic Programming | Book examples and Enhanced Code (`.py`) |
| **[Chapter 10](./Chapter_10)** | Greedy Algorithms | Greedy approach implementation (`.py`) |

*(Note: Missing chapter numbers reflect exercises that were skipped or conceptually merged).*

## 🚀 Getting Started

### Prerequisites

- **Python 3.x** to run the Python (`.py`) scripts.
- A **C++ Compiler** (such as GCC or Clang) to compile and run the `.cpp` files.

### How to Run

**Running Python Scripts:**

Navigate to the specific chapter directory and execute the script using Python:

```bash
cd Chapter_01
python3 binary_search.py
```

**Compiling and Running C++ Scripts:**

Navigate to the chapter, compile the source file, and run the executable:

```bash
cd Chapter_01
g++ binary_search.cpp -o binary_search
./binary_search
```
