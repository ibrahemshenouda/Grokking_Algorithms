# Chapter 2: Selection Sort

This chapter covers the differences between contiguous memory structures (Arrays) and scattered memory structures (Linked Lists). It also introduces the **Selection Sort** algorithm.

Selection Sort operates in **O(n²)** time. While it is easy to understand and implement, it is not very fast compared to other sorting algorithms like Quicksort.

## 📂 Contents

- `selection_Sort.py`: Python implementation of the selection sort algorithm.

## 🚀 How to Run

```bash
python3 selection_Sort.py
```
