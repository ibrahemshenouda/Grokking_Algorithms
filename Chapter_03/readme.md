# Chapter 3: Recursion

This chapter dives into **Recursion**, exploring how functions can call themselves. It explains the two essential parts of a recursive function: the *base case* and the *recursive case*, and introduces the concept of the Call Stack.

## 📂 Contents

- `countdown.py`: A simple recursive function that counts down to zero.
- `factorial.py`: A classic recursive implementation to calculate the factorial of a number.

## 🚀 How to Run

```bash
python3 countdown.py
python3 factorial.py
```
