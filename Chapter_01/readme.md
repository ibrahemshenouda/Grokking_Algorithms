# Chapter 1: Introduction to Algorithms

This chapter covers the basics of algorithm analysis, Big O notation, and introduces the **Binary Search** algorithm. 

Binary Search is a foundational algorithm that operates in **O(log n)** time, making it significantly faster than simple search (O(n)) for large, sorted datasets.

## 📂 Contents

- `binary_search.py`: Python implementation of the binary search algorithm.
- `binary_search.cpp`: C++ implementation of the binary search algorithm.

## 🚀 How to Run

**Python:**
```bash
python3 binary_search.py
```

**C++:**
```bash
g++ binary_search.cpp -o binary_search
./binary_search
```
