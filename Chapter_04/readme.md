# Chapter 4: Quicksort

This chapter introduces the **Divide and Conquer (D&C)** strategy, a well-known recursive problem-solving approach. It applies D&C to implement the **Quicksort** algorithm.

Quicksort is a highly efficient sorting algorithm that operates in **O(n log n)** time on average.

## 📂 Contents

- `01_Divide_and_conquer/`: Directory containing exercises and examples of the Divide and Conquer strategy.
- `02_Quicksort/`: Directory containing the implementation of the Quicksort algorithm.

cd 01_Divide_and_conquer
