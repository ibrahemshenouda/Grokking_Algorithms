# Chapter 9: Dynamic Programming

This chapter introduces **Dynamic Programming**, a powerful technique for solving complex problems by breaking them down into a collection of simpler, overlapping subproblems. 

The chapter often uses the classic "Knapsack Problem" as a primary example to demonstrate how dynamic programming grids are built and solved.

## 📂 Contents

- `book_example.py`: Python implementation of the dynamic programming example from the book.
- `enhanced_code/`: Directory containing an enhanced or optimized version of the dynamic programming algorithm.

## 🚀 Exploring the Code

You can run the standard book example directly:

```bash
python3 book_example.py
```

To explore the enhanced implementation, navigate into the subdirectory:

```bash
cd enhanced_code
# Run the scripts inside
```
