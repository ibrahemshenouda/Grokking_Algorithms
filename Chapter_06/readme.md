# Chapter 6: Breadth-First Search (BFS)

This chapter introduces **Graphs**, a way to model how different things are connected, and **Breadth-First Search (BFS)**, an algorithm used to traverse or search graph data structures. 

BFS helps answer two main questions:
1. Is there a path from node A to node B?
2. What is the shortest path from node A to node B?

## 📂 Contents

- `graph_and_BFS.py`: A Python script demonstrating how to represent a graph using a hash table and how to implement the BFS algorithm to find the shortest path.

## 🚀 How to Run

```bash
python3 graph_and_BFS.py
```
