# Chapter 5: Hash Tables

This chapter covers **Hash Tables** (also known as hash maps, dictionaries, or associative arrays). Hash tables use hash functions to map keys to values, providing incredibly fast lookups, insertions, and deletions with an average time complexity of **O(1)**.

## 📂 Contents

- `hash_table.py`: A Python implementation demonstrating how to create and use a hash table.

## 🚀 How to Run

```bash
python3 hash_table.py
```
